# PMF Deal Studio V2

This is the cleaner, redesigned standalone web app.

Files:
- index.html
- styles.css
- app.js

How to use:
1. Keep all three files in the same folder.
2. Double-click index.html.
3. The app opens locally in Chrome, Edge, Firefox, or Safari.
4. No Python, Streamlit, Node.js, or web server is required.

Design changes in V2:
- Cleaner top navigation instead of a permanent left sidebar
- Client context moved into an optional slide-down panel
- Three-step calculator flow: Select Product → Enter Terms → Review Deal
- Client-facing fields separated from fees and internal/advanced fields
- Sticky result panel on desktop
- Cleaner KPI hierarchy with one primary number and secondary metrics
- Product library changed from long accordions to compact cards
- Product matcher reorganized into a simpler intake workflow
- Better responsive layout for laptop and mobile screens

Important:
This calculator only performs math on terms entered by the user.
It does not create lender approvals, underwriting decisions, or live PMF pricing.
